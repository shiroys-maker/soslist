# Exact Book / Mini working-source preservation

Both hosts' original runner and reporter bytes and runner working-tree patches
are retained in named snapshots. The runner is byte-identical across hosts.
The canonical Legacy reporter uses Mini's device-aware configuration support,
which also accepts Book's original configuration; the original Book reporter
remains unchanged in its own snapshot. No source configuration values, logs,
clinical records, credentials or checkpoints are included.

These files preserve a future restoration choice. They are not packaged or
wired into active app execution. The new memo → Claim Evidence Review → Summary
pipeline is in daily-brief and does not use this old Portal collection runner or
reporter. Restoration would need its own full UI/runtime compatibility review.
